SamarthCare AI is an AI-powered early-warning anomaly detection and decision-support system designed to assist Care Coordinators supporting senior citizens living at home. 

Phase 1 provides realistic longitudinal multimodal synthetic data generation. Phase 2 delivers a transparent, explainable, personalized, non-diagnostic risk engine, alert lifecycle policy, ground-truth evaluation, and local FastAPI decision-support backend. The **Master Dataset Consolidation** losslessly integrates all raw observations, schedules, conversational check-ins, caregiver notes, and risk predictions into one unified master file.

> **CRITICAL MEDICAL DISCLAIMER**:
> All records, vital measurements, check-in dialogues, medication schedules, risk scores, and clinical scenarios generated by this project are **100% synthetic**. This system is engineered exclusively for AI benchmarking, software testing, and early-warning decision support. It is **not** a diagnostic device and does not establish clinical safety or medical efficacy.

## 1. Project Capabilities

- **Consolidated Master Dataset**: 18,000 senior-day rows (`data/processed/master_dataset.csv`) losslessly preserving all 55,581 vitals, 52,110 medication events, 12,828 check-ins, 15,933 annotations, 2,167 family notes, and Phase 2 risk predictions.
- **Personalized Daily Risk Scoring (0–100)**: Evaluates seniors against their personal baseline steady state using causal rolling windows (no future leakage).
- **Calibrated Risk Bands**: `LOW` (0–24), `MODERATE` (25–49), `HIGH` (50–74), and `URGENT_REVIEW` (75–100).
- **Independent Safety Tripwire Pathway**: High-urgency incidents (mechanical falls, hypertensive spikes $\ge 170\text{ mmHg}$, or hypoxia $\le 92\%\text{ SpO}_2$) immediately force minimum score $\ge 75$ (`URGENT_REVIEW`) even when other channels appear normal.
- **Sub-Category Saturation Caps**: Prevents unbounded score inflation from multiple correlated symptoms or repeated phrases.
- **Multilingual Dialogue NLP**: Robust rule-based extraction across Hindi, Hinglish, and English with clause-level negation propagation, historical context filtering, and uncertainty tracking.
- **Alert Lifecycle & Deduplication**: Manages `OPEN`, `ACKNOWLEDGED`, `ESCALATED`, and `RESOLVED` states, suppressing duplicate alerts during ongoing episodes.
- **Ground-Truth Evaluation (Quarantined)**: Evaluates episode-level recall, detection delay, false alerts per 100 days, and benchmarks against an unsupervised ML Isolation Forest detector.
- **Local FastAPI Backend**: RESTful decision-support API with coordinator acknowledgment and resolution actions.

## 3. Quickstart Commands

All commands run directly from the repository root:

### 3.1 Install Dependencies
```bash
python -m pip install -r requirements.txt
```

### 3.2 Execute Phase 1 Dataset Generation
```bash
python -m src.run_pipeline
```

### 3.3 Validate Phase 1 Dataset Invariants
```bash
python -m src.validate_dataset
```

### 3.4 Execute Phase 2 Early Warning & Risk Engine
Builds causal features, computes daily risk scores, manages alert lifecycle, evaluates against hidden ground truth, and consolidates the master dataset:
```bash
python -m src.run_phase2
```

### 3.5 Standalone Master Dataset Consolidation
Losslessly reconciles all raw and risk data into `master_dataset.csv`:
```bash
python -m src.consolidate_master_dataset
```

### 3.6 Run Interactive Demo Scenarios
Prints all 5 core clinical scenarios (Stable, Gradual Decline, Noisy Reading, Negation Note, Missing Telemetry):
```bash
python -m src.run_phase2 --demo-all
```

Or query any specific senior on any date:
```bash
python -m src.run_phase2 --demo --senior S0015 --date 2026-02-15
```

### 3.7 Run Full Automated Pytest Suite
Executes all 59 automated unit and integration tests:
```bash
python -m pytest -q
```
*Output: `59 passed in ~8.5s`.*

### 3.8 Run the FastAPI Backend
```bash
uvicorn src.api.main:app --reload --port 8000
```
Open `http://localhost:8000/docs` in your browser for Swagger UI.
